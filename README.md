# Arkanoid Game 

## Giới thiệu
Đây là project game Arkanoid được phát triển bởi nhóm 4 người như một bài tập lớn môn Lập trình Hướng Đối Tượng (OOP). Game được xây dựng bằng Java và JavaFX, tái hiện lại lối chơi cổ điển: điều khiển thanh đỡ để phá gạch và ghi điểm.
Team size: 4

## Công nghệ sử dụng
- Ngôn ngữ: Java
- Framework: JavaFX
- Mô hình: OOP (Object-Oriented Programming)

## Chức năng chính
- Điều khiển thanh đỡ (paddle) bằng bàn phím
- Bóng (ball) di chuyển và phản xạ với tường, thanh đỡ
- Hệ thống gạch (bricks) với va chạm và phá hủy
- Tính điểm theo số gạch phá được
- Kết thúc game khi mất bóng hoặc phá hết gạch
